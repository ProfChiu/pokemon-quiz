# Mei's Pokémon Trainer Quiz

A single-page browser quiz game for ~12-year-olds. Host character "Coach Mei" reacts to your answers.

- 10 questions per round, Rookie and Champion modes
- Timer, streak multiplier, 50/50 lifeline, ranks, high score
- Open `index.html` in a browser. No build step.
